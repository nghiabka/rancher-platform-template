# Phase 7 CI/CD Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Complete the phase 7 end-to-end CI/CD flow for `sample-api` with Docker Hub release images and a local GitOps overlay path.

**Architecture:** Keep the current template structure and finish the missing release wiring rather than redesigning it. GitHub Actions remains the primary release pipeline, GitLab CI stays in parity where the repo already has it, the local build helper remains a manual escape hatch, and ArgoCD continues to reconcile the `sample-api` overlay from GitOps.

**Tech Stack:** GitHub Actions, GitLab CI, Bash, Docker, Trivy, Kustomize, ArgoCD, Pytest, YAML.

## Global Constraints

- Docker Hub is the default release registry for CI-produced images.
- the local overlay can still target the local registry style used in the template.
- Keep changes small and aligned with the current repository style.
- Avoid introducing extra abstraction unless it directly supports the phase 7 release flow.
- Preserve the distinction between base image name, release image name, and local-lab image rewrite.

---

## File Structure

- `ci/github/sample-api-ci.yaml` — primary release pipeline: test, build, scan, push, and GitOps update.
- `ci/gitlab/sample-api-ci.yml` — GitLab parity pipeline for the same sample app flow.
- `bin/build-local-sample-api.sh` — manual build/push helper for local or lab usage.
- `gitops/apps/sample-api/base/deployment.yaml` — base deployment image reference and security context.
- `gitops/apps/sample-api/overlays/local/kustomization.yaml` — image rewrite for the local overlay.
- `gitops/apps/sample-api/overlays/local/deployment-patch.yaml` — mutable-tag pull policy patch.
- `gitops/clusters/local/sample-api.yaml` — ArgoCD Application entrypoint for the app.
- `tests/test_sample_api_image_registry.py` — existing string-level regression coverage for image and CI behavior.
- `tests/test_sample_api_gitlab_ci.py` — GitLab CI parity coverage.
- `tests/test_deployment_roadmap.py` — roadmap assertions for the phase 7 checklist/status text.
- `docs/deployment-roadmap.md` — phase 7 user-facing checklist and completion status.
